# OmniCell - Sistema de Importación y Venta de Pantallas y Repuestos

OmniCell es una aplicación de escritorio desarrollada en **C# con Windows Forms**, orientada a la gestión de un negocio dedicado a la **importación y comercialización de pantallas y repuestos para teléfonos celulares**.

El sistema tiene como propósito facilitar la administración de las principales actividades del negocio, permitiendo gestionar productos, proveedores, compras, ventas e inventario de manera organizada. Asimismo, contará con un sistema de autenticación para controlar el acceso de los usuarios según sus funciones dentro del negocio.

Una de las principales funcionalidades del sistema será el módulo de **ventas**, mediante el cual se podrán registrar las operaciones de venta de pantallas y repuestos, calcular automáticamente los totales y actualizar las existencias disponibles en el inventario.
